# The [MS-NLMP] NTLMv2 worked example, section 4.2 "Cryptographic Values for
# Validation": 4.2.1 Common Values, 4.2.4.1 Calculations, 4.2.4.2 Results and
# 4.2.4.3 Messages.
#
# These are what CI asserts for `auth/`. Session-setup frames are excluded from
# the fixture corpus by rule, and they are the only place NTLM and SPNEGO appear
# on the wire, so these two modules can have no captured coverage of their own.
# The specification's example stands in, and it is the better oracle in three
# ways: it fixes the nonce and the timestamp, so the expected bytes are
# reproducible exactly; it carries no real credential; and it comes from the
# specification rather than from the reference library's source, which is the
# same independence the licensing rule asks of the implementation itself.
#
# Every value below is transcribed from the published sections named beside it.
#
# Format: one `name = hex` per line. `#` opens a comment.
